# Medical Diagnosis Support & Disease Classification

An end-to-end medical classification machine learning lab project that evaluates, prunes, and tunes Decision Trees and Ensemble Classifiers on two distinct clinical datasets: **Breast Cancer Wisconsin (Diagnostic)** and **Early Stage Diabetes Risk Prediction**.

---

##  Quick Execution Guide (Faculty & Evaluator Instructions)

To execute the entire medical classification pipeline, train/tune all decision tree & baseline models, compute out-of-fold optimal decision thresholds, print performance tables, and generate diagnostic artifacts for **both datasets**, run the standalone Python script from your terminal:

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the complete pipeline script
python main.py
```

### What `main.py` executes:
- **Part 1 (Breast Cancer Wisconsin Diagnostic)**:
  - Data quality audit & missing value checks.
  - Stratified 80/20 train-test split ($N_{train} = 455$, $N_{test} = 114$).
  - EDA plot generation (`images/breast_cancer_eda.png`).
  - Benchmarking 5 models via 5-Fold Cross-Validation: Dummy Baseline, Basic Unpruned CART, Tuned & Pruned CART (via Cost-Complexity Pruning $\alpha$), Random Forest Classifier, and Logistic Regression.
  - Cost-Complexity Tree Pruning ($\alpha = 0.009362$) & Decision Rule Extraction (`images/breast_cancer_pruned_tree.png`).
  - Out-of-fold probability calibration & Threshold Selection for clinical target sensitivity (`images/breast_cancer_threshold_analysis.png`).
  - Holdout Test Evaluation: Confusion Matrix, ROC-AUC, PR-AUC, Sensitivity, Specificity, Brier score loss (`images/breast_cancer_confusion_matrix.png`, `images/breast_cancer_roc_curve.png`, `images/breast_cancer_pr_curve.png`, `images/breast_cancer_feature_importance.png`).

- **Part 2 (Early Stage Diabetes Risk Prediction)**:
  - Data loading from UCI ML Repository (ID: 529) / OpenML (ID: 44977).
  - Categorical label encoding and median imputation ($N = 520$).
  - Stratified 80/20 train-test split ($N_{train} = 416$, $N_{test} = 104$).
  - Benchmarking 5 models via 5-Fold Cross-Validation.
  - Threshold selection via Youden's $J$ statistic ($J = \text{Sensitivity} + \text{Specificity} - 1$).
  - Holdout Test Evaluation (`images/diabetes_confusion_matrix.png`, `images/diabetes_roc_curve.png`, `images/diabetes_feature_importance.png`).

- **Part 3 (Cross-Dataset Comparison & Clinical Insights)**:
  - Multi-dataset comparative summary table.
  - Clinical risk analysis on False Negative vs False Positive cost trade-offs.

Alternatively, you can open and run the interactive Jupyter Notebook:
```bash
jupyter notebook lab2_da.ipynb
```

##  Project Overview & Pipeline Architecture

Medical diagnosis support systems require high sensitivity (minimizing missed diagnoses / False Negatives) alongside clear model interpretability. This project explores non-linear decision boundary modeling using **Classification and Regression Trees (CART)**, cost-complexity pruning, decision threshold adjustment, and ensemble methods.

```

                                                                            │
┌────────────────────────┐      ┌────────────────────────┐                  │
```

##  Dataset 1: Breast Cancer Wisconsin (Diagnostic)

### Dataset Overview
- **Samples**: 569 (455 Train / 114 Test — 80/20 Stratified Split)
- **Features**: 30 continuous cell nucleus morphological features derived from digitized fine needle aspirate (FNA) images.
- **Target Variable**: `malignant` (1 = Malignant [212 samples, 37.3%], 0 = Benign [357 samples, 62.7%])
- **Data Quality**: 0 missing values, 0 duplicate rows, 0 constant columns.

### 5-Fold Cross-Validation Performance Comparison
Evaluating models using Stratified 5-Fold Cross-Validation on the training set:

| Model | Hyperparameters / Details | ROC-AUC | Sensitivity (Recall) | Balanced Accuracy |
| :--- | :--- | :---: | :---: | :---: |
| **Dummy Baseline** | Strategy: `prior` | 0.500 ± 0.000 | 0.000 ± 0.000 | 0.500 ± 0.000 |
| **Basic CART (Unpruned)** | Criterion: `gini`, Default | 0.916 ± 0.038 | 0.900 ± 0.046 | 0.918 ± 0.030 |
| **Tuned & Pruned CART** | `ccp_alpha = 0.009362` | **0.970 ± 0.016** | **0.929 ± 0.040** | **0.938 ± 0.019** |
| **Random Forest Classifier** | `n_estimators=300`, `max_depth=10`, `min_samples_leaf=4` | **0.990 ± 0.007** | **0.941 ± 0.033** | **0.957 ± 0.016** |
| **Logistic Regression** | Standard Scaled, `class_weight='balanced'` | **0.995 ± 0.005** | **0.965 ± 0.036** | **0.974 ± 0.014** |

### Decision Tree Complexity & Pruning Impact
- **Unpruned CART**: Depth = 7, Leaves = 16, Total Nodes = 31 (Overfitted to training noise).
- **Pruned CART**: Depth = 4, Leaves = 7, Total Nodes = 13 (High interpretability, higher CV ROC-AUC).

#### Key Extracted Decision Rules (Pruned Tree):
1. **Rule 1**: IF `worst perimeter <= 106.10` AND `worst concave points <= 0.13` THEN Class = **Benign** (Confidence: 98.4%).
2. **Rule 2**: IF `worst perimeter > 106.10` AND `worst texture > 16.19` THEN Class = **Malignant** (Confidence: 96.8%).

### Threshold Calibration & Holdout Test Results
In oncology screening, missing a malignant tumor (False Negative) carries far higher clinical cost than additional testing for a benign case (False Positive).

- **Default Threshold ($0.50$)**: Sensitivity = $0.907$, Specificity = $0.944$.
- **Calibrated Threshold ($0.15$)**: Sensitivity = **$0.953$**, Specificity = **$0.917$**.

#### Holdout Test Set Performance Metrics (Threshold = 0.15):
- **Sensitivity (Recall)**: `0.9535` (41 of 43 malignant cases detected)
- **Specificity**: `0.9155` (65 of 71 benign cases correct)
- **Balanced Accuracy**: `0.9345`
- **Precision (PPV)**: `0.8723`
- **F1 Score**: `0.9111`
- **ROC-AUC**: `0.9784`
- **PR-AUC**: `0.9621`
- **Brier Loss Score**: `0.0531`

##  Cross-Dataset Comparison & Clinical Insights

| Dataset | Samples | Features | Class Prevalence | Best Performing Model | Test ROC-AUC | Test Sensitivity | Test Specificity | Test Balanced Acc |
| :--- | :---: | :---: | :---: | :--- | :---: | :---: | :---: | :---: |
| **Breast Cancer** | 569 | 30 | 37.3% (Malignant) | Logistic Regression / Random Forest | **0.9784** | **0.9535** | **0.9155** | **0.9345** |
| **Diabetes Risk** | 520 | 16 | 61.5% (Positive) | Random Forest Classifier | **0.9848** | **0.9688** | **0.9250** | **0.9469** |

### Key Findings & Recommendations:
1. **Pruning Prevents Overfitting**: Unpruned Decision Trees create deep, complex trees (depth 7+) that overfit noise. Cost-Complexity Pruning reduces depth to 4 without sacrificing diagnostic accuracy.
2. **Threshold Tuning Save Lives**: In medical AI, adjusting decision thresholds from 0.50 to lower values (e.g. 0.15) increases Sensitivity to > 95%, ensuring minimal missed malignant/risk cases.
3. **Interpretability vs. Performance**: Simple Pruned CART trees provide transparent, boolean IF-THEN rules directly interpretable by clinicians, while Random Forest ensembles yield slightly higher ROC-AUC.
4. **Clinical Disclaimer**: All models are intended purely for academic and educational evaluation and must NOT be used for real-world clinical diagnosis.
